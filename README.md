# 5-Day-AI-Agents-Intensive-Course-with-Google

🚀 5-Day AI Agents Intensive Course with Google
Kaggle – Mentor3 Program

Welcome to my repository for the 5-Day AI Agents Intensive Course with Google!
This repo serves as a structured archive of all learnings, assignments, notes, codelab solutions, and resources I completed throughout the program.

This course is designed by Google researchers and engineers to help developers understand and build AI agents, covering models, tools, memory, orchestration, evaluation, and productionization.

📚 Course Overview

Over 5 days, Google’s ML experts guide you through:

Foundations of AI Agents

1. Tooling & Interoperability using Model Context Protocol (MCP)

2. Context engineering with Sessions & Memory

3. Agent quality, observability, evaluation, HITL

4. Multi-agent systems & deployment to production

Each day includes:

✔ A detailed Google whitepaper

✔ A NotebookLM podcast summary

✔ Hands-on codelabs on Kaggle

✔ Live streams with Google, NVIDIA, Cohere speakers

✔ Community discussions via Kaggle Discord
